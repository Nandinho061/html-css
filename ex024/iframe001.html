exercicios de iframe

iframe é um elemento HTML que permite incorporar outro documento HTML dentro do documento atual. Ele cria uma janela ou dentro da página, permitindo exibir conteúdo de outra fonte, como uma página da web externa, um vídeo, um mapa ou qualquer outro recurso HTML.
